# 4HD PRINT

Official website and e-commerce platform for **4HD PRINT LLC**.

4HD PRINT is a printing, graphic design, and web solutions business.  
This project provides the company's public website, online store, service information, and internal tools for managing customer requests.

## Project Status

Currently under active development.

The website is being developed locally and will be deployed to production once the main functionality, content, testing, and documentation are complete.

## Technology

The project is built primarily with:

- WordPress
- WooCommerce
- PHP
- HTML
- CSS
- JavaScript

The website uses a custom WordPress theme developed specifically for 4HD PRINT.

## Main Areas

The website currently includes or is being developed to include:

- Print Services
- Promotional Products
- Graphic Design Services
- Web Solutions
- WooCommerce Online Store
- Website Project Estimator
- Website Quote Management
- Shipping and Local Pickup

## Documentation

Detailed project documentation is located in the `/docs` directory.

Planned documentation:

- `TECHNICAL.md` — Architecture, custom functionality, code structure, and development decisions.
- `USER-GUIDE.md` — Instructions for managing the website through WordPress.
- `DEPLOYMENT.md` — Local development, migration, production deployment, and maintenance procedures.
- `SECURITY.md` — Security decisions, protections, and production checklist.

Documentation is developed progressively as each area of the website is reviewed and finalized.

## Development Workflow

Major functionality should follow this general workflow:

1. Develop or modify the feature.
2. Test the functionality locally.
3. Review security and data handling when applicable.
4. Update relevant documentation.
5. Commit the completed milestone to Git.

## Repository

This repository contains the source code and documentation for the 4HD PRINT website.

Production customer data, orders, credentials, API secrets, and other sensitive information should not be committed to the repository.
